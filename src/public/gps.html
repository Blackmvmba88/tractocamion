Transmitir desde este dispositivo

Usa esta función dentro de la unidad: enviará la ubicación de este teléfono o computadora a la unidad seleccionada. El navegador debe permitir el acceso a la ubicación.

GPS detenido. No se está compartiendo tu ubicación.

Mantén esta página abierta y el teléfono encendido. El seguimiento puede pausarse al bloquearlo o pasar al segundo plano. Desde otro teléfono se necesita una dirección HTTPS; localhost sólo funciona en el dispositivo que ejecuta el servidor.

Rastreadores de las unidades

Crea una credencial por rastreador. Se guarda únicamente su huella; la clave completa se muestra una sola vez.

Guarda esta clave en la configuración privada del rastreador. No la compartas ni la publiques.

Recepción HTTP JSON: POST /api/gps/ingest. Usa HTTPS fuera de localhost. Los rastreadores con protocolos propios necesitarán un adaptador. El firmware inicial ESP32 usa Wi-Fi; la conectividad celular es una ampliación posterior.
